# Data Structures and Algorithms

C implementations of classic data structures and algorithm exercises.

> Academic context: this directory contains course lab or coursework solutions.

## Topics

- AVL trees and linked lists
- Huffman coding
- Polynomial operations
- Expression evaluation
- Sorting algorithms
- Tour-guide graph operations

## Compile and Run

```powershell
gcc -std=c17 -Wall -Wextra -o avl AVL_Tree.c
.\avl.exe
```

Programs are independent exercises. Compile one source file at a time.
